# Hochzeitswebsite Swantje & Sören

## Veröffentlichung auf GitHub Pages
1. ZIP-Datei entpacken.
2. Im Repository `soeren-swantje/Hochzeit-2027` auf **Add file → Upload files** gehen.
3. Den **Inhalt** dieses Ordners hochladen: `index.html`, `styles.css`, `app.js`, `danke.html` sowie den Ordner `assets` und die beiden QR-Code-Dateien.
4. Unten auf **Commit changes** klicken.
5. Die Website ist anschließend unter `https://soeren-swantje.github.io/Hochzeit-2027/` erreichbar.

## Gäste-Links
- Nur Nachmittag: `https://soeren-swantje.github.io/Hochzeit-2027/?gruppe=tag`
- Nachmittag und Abend: `https://soeren-swantje.github.io/Hochzeit-2027/?gruppe=abend`

Die passenden QR-Codes liegen als PNG-Dateien bei.
