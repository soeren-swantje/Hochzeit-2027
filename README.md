# Hochzeit 2027 – Version 2.0

## Upload auf GitHub
1. ZIP entpacken.
2. Im Repository `soeren-swantje/Hochzeit-2027` auf **Add file → Upload files** klicken.
3. Alle entpackten Dateien gleichzeitig in das Upload-Feld ziehen.
4. Bei gleichnamigen Dateien überschreibt GitHub nach dem Commit die alte Version.
5. **Commit changes** anklicken.
